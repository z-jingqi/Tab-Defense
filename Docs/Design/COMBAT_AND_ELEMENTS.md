# 玩法、箭矢、成长与四元素

## 1. 核心循环与操作

竖屏无尽生存：敌人上方入场，下行漏怪扣血；玩家点击战场任意非 UI 位置，在点击处生成垂直向上的箭矢。没有底部发射区。击杀得经验，升级时暂停现场并三选一，选完恢复。玩家血量为零失败，重开清除本局成长和场上状态，没有固定时间胜利或波次。

有效战斗时间驱动移动、敌人/Boss 出场、攻击冷却、元素恢复、技能和持续伤害。手动暂停、升级、切后台时均冻结。全局攻击冷却未好时点击无效，不排队、不消耗元素。

UI 按钮不穿透到战场。底部仅显示已解锁的元素；按火、雷、冰、风顺序以等间距组成水平居中组：偏移 `(索引-(数量-1)/2)*间距`。1 个正中，2 个左右对称，3/4 个同理。未解锁不占位。右侧预览当前箭矢颜色与攻击冷却。

## 2. 箭矢与命中

| 项目 | 初始值 / 规则 |
| --- | --- |
| 基础伤害 | 28 |
| 点击冷却 | 0.32 秒，升级乘 0.9，最低 0.10 秒 |
| 速度 / 碰撞半径 | 11 世界单位/秒；0.13，尺寸升级按比例放大 |
| 分裂 | 增加同次箭组内的平行箭，全部直飞向上；默认上限 3 |
| 侧箭 | 65% 伤害；每组一个主箭为全伤害 |
| 连射 | 点击后每隔 0.1 秒追加一个箭组，默认最多 3 组 |
| 穿透 | 初始 0，即命中一个后消失；最多额外 3 个不同敌人 |
| 暴击 | 初始概率 5%，伤害倍率 1.5；每次直接箭命中独立判定 |

每次有效点击保存伤害、元素、分裂、连射、穿透、暴击参数快照；切换元素或中途升级不改已发箭和待发连射。扫掠检测高速命中；每支箭记录敌人生成 ID，不重复打同一目标。盾牌/次数护甲阻挡仍算命中，消耗该箭一次穿透机会。

## 3. 成长

初始玩家 HP 120，首次升级 12 XP，之后每级加 6 XP；经验保留，可累计多次选择。三选一去重，达到上限的分裂/连射/穿透、冷却和尺寸不再出现；满血不出现回血。未解锁任一元素前，每次保证至少一个元素解锁选项，但不强制选择；解锁后不重复提供该元素解锁。

| 升级 | 效果 |
| --- | --- |
| 伤害 | 当前伤害乘 1.28 |
| 箭尺寸 | 尺寸参数 +0.13，最高 2.8，初值 1.05 |
| 冷却 | 当前冷却乘 0.9，最低 0.10 秒 |
| 分裂 / 连射 / 穿透 | 相应数量 +1，遵守上限 |
| 暴击率 / 暴击倍率 | +5 个百分点（最高 100%）/ +0.25 倍 |
| 击杀连锁 | 击杀产生范围伤害，追加选择强化伤害与范围；限制传播深度、队列与每帧数量 |
| 最大生命 / 恢复 | 最大 HP +25 且补同额；或恢复最大 HP 的 35% |
| 元素解锁 | 满数量解锁对应按钮，仍需玩家主动选中 |

## 4. 元素使用与资源

元素持续选中，点击战场发附魔箭；再点同元素取消，或切换其他已解锁且有数量的元素。所有元素共享箭矢攻击冷却，切换不刷新冷却。一次成功点击消耗 1 次元素数量，分裂和连射共享该次消耗。池不足拒绝本次攻击，不扣资源。

各元素容量默认 3，分别按时间逐个补充到上限；消耗时启动补充，不因再次消耗而重置已有补充进度。耗尽自动切普通箭；补充后不自动选回。数量为零仍显示按钮及补充倒计时，不能选中。

| 元素 | 命中效果 | 初始参数 |
| --- | --- | --- |
| 火 | 命中点周围次级伤害；存活者灼烧，包含直接目标 | 半径 0.75；次伤 50%；灼烧每秒 18% 箭伤、2 秒；6 秒/次 |
| 雷 | 从主目标位置寻找最近未命中目标，逐个跳跃；同次链不重复 | 跳距 1.3；最多额外 3 目标；各 55% 箭伤；7 秒/次 |
| 冰 | 小范围减速；持续期间累计命中 3 次冻结 | 半径 0.65；速度乘 0.5，2 秒；冻结 0.6 秒；6 秒/次 |
| 风 | 小范围次伤，将目标短时拉向命中点 | 半径 0.9；次伤 20%；拉速 1.6、持续 0.75 秒；7 秒/次 |

次级伤害不二次暴击，也不递归触发元素。灼烧取更强每秒伤害并刷新持续时间，不按箭数量无限叠加；到期后重置强度。冰冻结期间不累计下一轮冻结。控制效果按敌人抗性折减；Boss 默认仅 40% 控制强度。

次数护甲阻挡直接箭：该箭不触发元素，持续伤害/范围伤害不剥层且被护甲阻挡。盾牌优先承受所有伤害，单次溢出不伤本体；盾存在时控制无效，元素不能以被盾阻挡的箭为中心触发。盾碎进入短暂失衡，再用后续箭攻击本体。命中链传来的范围伤害仍按接收目标的防御结算。防御优先级见 Boss 文档。

## 5. 搭配与功能边界

风聚怪后火清群、冰延缓后雷跳链、连射拆次数护甲、伤害/暴击破盾。无额外元素反应配方，不增加第二次点击手势或独立技能释放键。颜色是占位反馈，正式元素动画/音效与山海经赛璐美术后续制作。
