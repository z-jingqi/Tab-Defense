# 限制与待验证

- 云环境没有 Unity Editor、C# 编译器或 Xcode；导入编译、Unity 测试、iOS/Android 构建及真机测试尚未执行。
- 当前为英文原型 UI、几何敌人与箭矢占位图。山海经角色、草地场景、赛璐璐美术、元素专属特效和音效未制作。
- 元素功能与箭矢成长参数尚未经实际游玩调平；无元素反应配方，无存档/图鉴/局外养成。
- 安全区、触控、后台恢复、音效和帧率尚未在 iPhone 验证；60 FPS 为目标。
- 满池会暂缓出怪、拒绝新攻击、推迟连射或丢弃视觉反馈；连锁有队列、深度与每帧预算。大量穿透、元素范围和连锁同时发生的性能待测。
- 点击处直接生成箭矢，因此可在敌人附近射击；这是当前全屏自由发射规则。UI 按钮与箭矢预览区域拦截射击，其他战场空白可点击。
- 单帧最多推进 0.05 秒，严重卡顿会放慢游戏时间。
- 分裂目前为平行箭，侧箭较弱，不会在命中后再分叉；元素切换采用持续选中方式，直到取消、切换或数量耗尽。
- Boss 数据保留但默认不随机生成；旧中央水晶组件/Prefab 保留兼容，运行时隐藏。没有波次或最终胜利路径。
