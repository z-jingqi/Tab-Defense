## 本地必须验收

1. 国际版 Unity 6000.3.25f1 导入编译，运行全部 EditMode / PlayMode 测试；当前没有运行结果 XML。
2. 正常局内持续到 Boss 出现、击杀和再次出现，验证三组合轮换；本地可临时缩短 `Bosses` 时间。
3. 云内敌人不泄露本体、血条、状态、数字、火冰/死亡反馈、命中声音和箭矢消失点；不同屏幕比例、震屏时也不穿透。云外正常显示，云内依然可盲射击杀。
4. 暂停/升级/后台冻结路线、Boss 技能、盾计时、回血、云、箭矢/连射和元素恢复；重开/失败无残留。
5. 穿透不重复拆同一 Boss 护甲，盾破不溢出，灼烧不剥护甲，实际本体伤害可打断回血；冰风遵守抗性。
6. 满池不额外消耗资源、不突破召唤上限；大量目标/血条/范围伤害时移动端帧率与内存。
7. iPhone 触屏、刘海安全区、Xcode 导出/签名/安装与 Android 构建。
