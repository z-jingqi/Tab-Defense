# Tab Defense

Unity 6.3 LTS 6000.3.27f1，Built-in 2D。

## 运行

在 Unity Hub 使用「添加 → 从磁盘添加项目」选择仓库根目录，打开 Assets/Scenes/Main.unity，Play 后点击 START SURVIVAL。Game 视口建议 9:16。

## 当前玩法

英雄在底部水平拖动，支持单指触摸与编辑器鼠标，松手停止。无论有没有敌人，箭矢都按攻速持续严格竖直发射，横移对准敌人，没有追踪。攻击速度由英雄属性控制。

普通小兵沿出生 x 竖直推进，进入英雄脚点上方 1.7 世界单位的近身区域后，持续沿最短直线追击英雄当前位置。按角色半径保持近战距离，预警 0.3 秒后重新检查范围并攻击，冷却 1.25 秒；英雄离开范围则取消预警继续追击。英雄生命为零才失败，没有可见横线或横向排队轨道。

英雄绿血条、小兵红血条在头顶常显。经验细条贴屏幕最底边全宽显示，不拦截拖动。相机纯色清屏。英雄暂用几何占位形象；小兵为静态绘制精灵，普通兵可见高度约占有效战场 10%。

击杀获得经验，升级保留伤害、箭尺寸、攻击速度、多发、连发、穿透、暴击、最大生命、回血和连锁爆炸等基础成长。暂停及升级期间停止战斗；重开清空角色与箭矢池状态。
