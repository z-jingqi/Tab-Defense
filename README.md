# 点击防线 · Tap Defense

点击发射箭矢，主动搭配火、雷、冰、风，拦截从上往下移动的敌人。

Unity Technologies 国际版 Unity 6.3 LTS `6000.3.25f1`，C#，Built-in 2D，竖屏；iPhone 优先，Android 次要。工程使用简单占位资源，山海经题材与赛璐璐美术、正式元素特效留待后续制作。应用显示名“点击防线”，英文标题 `TAP DEFENSE`，默认应用标识符 `com.prototype.tapdefense`。

详细规则见 [设计文档目录](Docs/Design/README.md)：涵盖箭矢、成长、四元素、敌人路线、Boss 技能与云层信息遮蔽。

## 本地运行

1. 用国际版 Unity Hub 添加本仓库根目录，等待依赖解析与编译。
2. 打开 `Assets/Scenes/Main.unity`，Play，点击 `START SURVIVAL`。
3. 鼠标左键或单指点击战场任意位置，从点击位置生成向上直飞的箭矢。没有底部发射区限制。

## 当前规则

- 无波次、无倒计时通关；以存活时间和击杀数计分。敌人从屏幕上方生成，完全离开下方扣血，漏怪不奖励经验。血量为零结束，可重新开始。
- 击杀获得经验，达到门槛后暂停战斗，随机三选一；选完全部升级后继续原现场。首次需要 12 XP，每级需求增加 6 XP，剩余经验保留。
- 普通箭默认命中一次消失；穿透升级增加命中数量，同一箭不重复命中同一敌人。扫掠检测避免高速箭穿过目标。
- 分裂升级增加平行箭（仍垂直飞行），侧箭默认造成 65% 伤害；连射升级使一次点击按间隔追加箭组。两者默认最多各 3，穿透最多额外 3 次。
- 可升级基础伤害、箭尺寸、射击冷却、暴击率、暴击伤害、击杀连锁、最大血量和回血。暴击默认 5%，倍率 1.5；元素附加伤害不独立暴击。
- 初始没有元素按钮。火、雷、冰、风只在选择相应解锁升级后出现，已解锁元素不会重复出现在解锁选项中。未解锁任何元素时，每次升级保证至少提供一个可选元素，玩家仍可选其他强化。
- 底部已解锁按钮按火、雷、冰、风顺序整体水平居中，只有一个居中，两个左右对称，以此类推。未解锁元素不占位。
- 点击元素按钮选中，再点击战场发射附魔箭；再点已选按钮回到普通箭。可自由切换已解锁且有数量的元素。按钮操作不会发射箭或消耗元素，也不会重置射击冷却。
- 每次成功发射消耗当前元素 **1 次数量**，本次分裂与全部连射共享该次消耗。冷却未结束或对象池不足时不消耗。箭矢记录发射时的属性，切换元素不改变已发射箭和待发连射。
- 元素默认容量 3，按各自冷却逐个补充，不消耗数量时不会超过上限；数量为零自动切回普通箭。恢复数量不会自动重新选中。暂停、升级和后台暂停期间不恢复数量、不推进战斗。
- 底栏显示数量及下一次补充倒计时，右侧箭矢预览显示当前元素颜色和射击冷却。UI 控件阻挡战场点击，空白区域可射击。

| 元素 | 当前功能 | 默认补充间隔 |
| --- | --- | --- |
| 火 | 命中点周围附加伤害，存活目标持续灼烧 | 6 秒/次 |
| 雷 | 从命中目标向附近最多 3 个不同目标跳跃伤害 | 7 秒/次 |
| 冰 | 小范围减速，累计 3 次冻结；Boss 控制减弱 | 6 秒/次 |
| 风 | 小范围附加伤害，将目标短暂拉向命中点 | 7 秒/次 |

元素使用顺序可搭配，例如风聚怪后用火、冰减速后切雷；当前没有额外的元素反应配方。已有命中数字、闪白、死亡碎片、震屏及音效保留，本轮新增基础敌人/Boss 状态提示与不透明云层占位遮罩，正式元素动画与音效之后制作。

## 敌人与 Boss

- 普通直行、快速 S 形、重甲走走停停、冲刺怪蓄力冲刺；按 0/15/30/45 秒逐步加入普通随机池。路线、出场时间、权重、控制抗性可分别配置。
- 60 秒出现首个 Boss，从顶部进入上半场驻留；上一只死亡后 90 秒出现下一只，同场最多一只。组合循环：召唤＋盾、召唤＋云、次数护甲＋回血。召唤怪默认不给经验，最多同时 12 个。
- 盾有 180 HP，最多持续 7 秒，吸收所有伤害且不溢出；破盾失衡 1.5 秒。次数护甲 8 层，仅直接箭矢扣层，抵消对应命中；持续/范围伤害不扣层且被阻挡。挡住的主箭不触发元素。
- 回血引导 3 秒，每秒恢复 6% 最大生命，累计受到 8% 最大生命的本体伤害可打断。Boss 默认控制抗性 60%。
- 云层只有一片，高度硬限制在战场顶部 1/3 内，默认高 26%、宽 65%、持续 6 秒。遮住敌人、血条、状态、命中数字/死亡反馈和区域内箭矢；盲射仍有效。来源在云内的反馈直接抑制，不会飘出云外；云内命中/死亡无局部音效。Boss 死亡、失败和重开清云。
- 云只隐藏战场，不遮挡玩家 HUD；隐藏目标不会通过 Boss HUD 泄露血量或防御信息。

## Inspector 与结构

在 `Assets/Data/GameConfig.asset` 调整：

- `Progression`：基础攻击、冷却、暴击、升级增量、分裂/连射/穿透上限及连射间隔。
- `Elements`：四元素类型、容量、补充间隔、范围、伤害比例、持续时间、灼烧/跳雷/冰冻/聚怪参数。元素类型必须唯一，排列不影响按钮顺序。
- `Spawning / Difficulty Growth Per Minute`：普通出怪节奏、上限、倍率和难度增长。
- `Enemies`：5 类敌人的生命、速度、漏怪伤害、经验、半径、身份、路线、出场时间、权重和控制抗性。普通随机权重已迁移到每个敌人定义。
- `Bosses / Boss Profiles`：Boss 调度、驻留位置、召唤、单片云、回血、护甲、盾以及技能组合。可暂时把首次出现时间调小便于本地验证，完成后恢复 60 秒。
- `Bullet Speed / Radius / Pool Size / Pending Burst Limit`：箭矢与待发连射池。敌人、箭矢、连射任务、基础反馈均使用固定容量池；满池时拒绝新攻击或延后待发连射。

`Core` 为不依赖 Unity 的成长、元素、路线、Boss 调度和伤害防御模型；`GameController` 协调输入和战斗；`BulletSystem` 管箭矢与连射；`EnemySystem / EnemyView` 管命中与元素状态；`BossDirector` 管技能；`FogOfWar` 管单片遮蔽；`GameHud` 管界面。核心逻辑不接平台 SDK，没有广告、内购、联网或微信 SDK。

## 构建与验证

- iOS：菜单 `Tap Defense > Export iOS Xcode Project`，按 [iOS 构建说明](Docs/IOS_BUILD.md) 在 Mac/Xcode 签名安装。
- Android：菜单 `Tap Defense > Build Android APK`。
- Unity 测试：Test Runner 的 EditMode、PlayMode，或本地执行 `bash Tools/run_unity_checks.sh`。
- 结构检查：`python3 Tools/validate_project.py`（Python 3、Pillow、PyYAML）。

当前云环境未安装 Unity、C# 编译器或 Xcode，未执行 Unity 导入编译、运行测试及原生构建。见 [测试报告](Docs/TEST_REPORT.md) 与 [限制清单](Docs/KNOWN_ISSUES.md)。
